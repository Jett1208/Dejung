# 0002: Mobile and Tablet First Touch UX with PWA Support

We decided to optimize the UI/UX primarily for Mobile and iPad viewports, implementing a sticky bottom summary bar, touch-friendly tap targets (minimum 44x44px), decimal-optimized numeric keyboards (`inputMode="decimal"`), and Progressive Web App (PWA) manifest configuration.

This decision was chosen because the primary daily user context is on smartphones and tablets, where traditional desktop side-by-side layouts degrade and long scrolling causes users to lose context of their unallocated budget. A sticky bottom summary ensures real-time financial visibility during entry, and PWA capabilities allow the app to be installed directly to the iOS/iPadOS home screen.
